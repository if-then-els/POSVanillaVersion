# SwiftPOS Printer Setup

## Supported Hardware

| Type | Tier | Connection | Tested |
|------|------|------------|--------|
| 58mm Bluetooth Thermal (XPrinter XP-N160I, GPrinter) | Standard+ | Bluetooth | Android via `capacitor-printer` |
| 80mm USB/Network (Epson TM-T20, Star TSP100) | Premium | USB OTG / LAN 9100 | Native + web proxy |
| PDF / Browser | All | Fallback | `window.print()` |

## Mobile (Capacitor) - Recommended

1. **Install plugins** (after `public` built):
```bash
npm i @capacitor/core @capacitor/cli @capacitor/android @capacitor/ios
npm i @capacitor/preferences @capacitor/network @capacitor/haptics @capacitor/share
npm i capacitor-printer  # or @robingenz/capacitor-printer
npx cap init SwiftPOS com.codecine.swiftpos --web-dir=public
npx cap add android
npx cap sync
```

2. **Bridge** in `public/js/capacitor-bridge.js:1` auto-detects `window.Capacitor.isNativePlatform()` and routes `SwiftBridge.printReceipt({html})` → native `Printer.print` or web fallback.

3. **Print flow** `public/js/printer.js:1`:
```js
await Printer.printSale(saleId) // fetches /receipt/:id, builds HTML + QR, calls bridge
```

## Web / Desktop

- **Fallback:** Always `window.print()` from `services/printerService.js:1` HTML.
- **QZ Tray** (optional): Install [qz.io](https://qz.io) for raw ESC/POS over USB without user dialog. Configure `qz.websocket.connect()` then `qz.print(config, [{type:'html', data: html}])`.
- **Network (Epson LAN):** If printer has IP `192.168.1.50`, Premium can POST ESC/POS via backend proxy `POST /api/print/proxy {ip, port:9100, escposBuffer}` — buffer generated by `escpos` lib (add `npm i escpos escpos-network` on server).

## Backend

- `services/printerService.js:1.generateReceiptPayload(sale,store)` returns `{items,total,qrUrl}` used by both HTML and ESC/POS.
- Receipt HTML includes QR (`https://api.qrserver.com/...?data=receiptNo`) for verification.

## Testing Without Hardware

1. Use browser print preview (always works).
2. Android: `npx cap open android` → Run on emulator → sale → Print → system share sheet appears.
3. Check `public/verify-password.html` style QR — scan to verify receiptNo maps to `/receipt/:id`.

## Troubleshooting

- Bluetooth not pairing → enable Location permission on Android 12+.
- Text garbled → ensure printer codepage `cp-437`, send `ESC t` init.
- Network 9100 blocked → check firewall, test `telnet 192.168.1.50 9100`.
